# 📚 BookShare  

A **community-driven academic book sharing platform** that enables students and readers to **list, request, buy, and sell books** securely. Built with **React** for a modular UI and **Supabase** for real-time backend functionality, BookShare fosters a seamless and trusted environment for book exchanges.  

---

## 🚀 Features  

- 🔑 **Secure Authentication** – User login and signup powered by Supabase Auth  
- 📖 **Book Listings** – Add, view, and manage available academic books  
- 🤝 **Request & Accept Flow** – Users can request books and owners can accept or reject requests  
- 📲 **QR Code Verification** – Ensures **secure and authenticated book exchanges** during handovers  
- 🔄 **Real-time Updates** – Live sync of listings and request statuses  
- 🖼️ **Clean UI** – Built with React components for intuitive user experience  

---

## 🛠️ Tech Stack  

- **Frontend**: React (component-based UI)  
- **Backend**: Supabase (Auth, Database, Real-time)  
- **Authentication**: Supabase Auth  
- **Verification**: QR Code-based system
